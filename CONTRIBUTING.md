# Contributing

This repository is an automated public mirror, not an authoring surface. Pull requests that edit
record segments, the live tail, manifests, checkpoints, or archive exports cannot become canonical
Systema Constructum acts.

- To add or contest ontology content, use the recorded gameplay and governance surfaces at
  [systema.quartermachines.website](https://systema.quartermachines.website).
- To report a reproducible verification problem, use the
  [systema-verify repository](https://github.com/saidthefox/systema-verify).
- To report possible exposure of private or security-sensitive information, follow
  [SECURITY.md](SECURITY.md) and do not post the material publicly.

Documentation corrections about this mirror may be proposed as issues or pull requests, provided
they do not alter generated record artifacts.
